# 声の登録：朗読台本と録音のやり方（約3分）

自分の声の「手本」を作るための録音です。ここで録った声が、翻訳後の読み上げ（本人の声での合成）の基準になります。
**録音の質が、声の似かたをいちばん大きく左右します**（調査上、手本の取り方が最大の要因）。
下の手順どおりに、静かな部屋で、ふだん会議で話すときの自然な声で録ってください。

- 所要時間：同意文（約15秒）＋日本語の朗読（約90秒）＝ 約2分。外国語（任意）を足しても約3分。
- 読む文は、すべてこのプロジェクトのための書き下ろしです（既存の朗読コーパスの文は使っていません）。
- 録音したら、`voiceprofile build` に渡すと、きれいな手本が自動で切り出されます（コマンドは `src/voiceprofile/README.md`）。
- 機械が読む同じ内容のファイルが `script_ja.json` です。**文を直すときは、この md と json の両方を直してください**（テストが一致を確認します）。

画面にこの台本を出したいときは、`uv run voiceprofile script`（`src/voiceprofile/README.md` 参照）。

## 1. 録音の条件（これだけは守る）

| 項目 | やること | 理由 |
|---|---|---|
| 場所 | **静かな部屋**。エアコン・換気扇・パソコンのファン・窓の外の音を止める。カーテンや布のある部屋が良い（響きが少ない） | 雑音と響きも「声の一部」として手本に入ってしまう |
| マイクの距離 | **口元から 10〜20 cm**。口の真正面より少し斜め下（息が直接当たると「ボフッ」と鳴る） | 近すぎると息の音、遠すぎると雑音と響きが増える |
| 距離と音量 | **録音のあいだ、同じ距離・同じ音量・同じ姿勢**。マイクの音量設定は録音の前に決め、途中で変えない | 手本どうしが揃うほど、声がぶれない |
| 音の大きさ | いちばん大きい音でも**割れない**こと（録音ソフトのメーターが赤にならない）。目安は最大でメーターの半分〜8割 | 音割れは直せない |
| 保存形式 | **48 kHz（44.1 kHz でも可）・モノラル・WAV**（16 bit か 24 bit） | 声の細かい特徴は高い音域に出る。16 kHz の録音は手本に向かない |
| **ノイズ除去・音声分離は使わない** | 録音ソフトの「ノイズ除去」「自動音量調整（AGC）」「エコー除去」「ノイズゲート」、Zoom・Teams などの「背景ノイズ抑制」は**全部オフ** | かけると声の特徴が変わり、似なくなる（調査: ノイズ除去した手本は類似度が下がる） |
| 話し方 | **演技をしない**。感情をこめず、ふだん会議で説明するときの自然な調子で | 感情は別の仕組みで再現する。手本にトーンの偏りがあると、毎回その調子になってしまう |
| 雑音 | 咳・咳払い・鼻をすする音・紙をめくる音・キーボード/マウスの音・着信音を出さない。出たときはその文を最初から読み直す | 手本にそのまま入る |
| 最初と最後 | 録音ボタンを押したら**2秒、黙る**。読み終わっても**2秒、黙ってから**止める | 部屋の雑音の大きさを測るのに使う（手本の「きれいさ」の判定に必要） |

### 道具の例
- パソコンのマイクより、**ヘッドセットや外付けのマイク**の方が安定します（口元に近づけられる）。USB のマイクで十分です。
- 録音ソフトは **Audacity**（無料・Mac/Windows 共通）が簡単です。
  - 「プロジェクトの音源周波数」を **48000 Hz**、チャンネルを **モノラル** にして録音。
  - 録音後、「ファイル → 書き出し → WAV として書き出し」（Microsoft の WAV、16 bit か 24 bit）。
  - Windows は「設定 → システム → サウンド → マイクのプロパティ」で「オーディオ強調（音声強調・ノイズ抑制）」が**オフ**であることを確認。
  - Mac は「メニューバー → マイクモード」を**標準**にする（「声を分離」にしない）。
- スマホのボイスメモ（m4a）でも読み込めますが、WAV の方が確実です。変換するなら：
  `ffmpeg -i 録音.m4a -ac 1 -ar 48000 -c:a pcm_s16le rec.wav`

## 2. 録音の手順

1. 部屋・マイク・設定を整えて、録音を開始する（**2秒黙る**）。
2. **同意文**を読む（下の「3. 同意文」。【　】の所は自分の情報に置き換えて読む）。
3. **日本語の朗読**を、上から順番に1文ずつ読む（下の「4. 日本語の朗読文」）。
   - **文と文のあいだは1秒ほどあける**（息継ぎ）。読点（、）では止まらず、続けて読む。
   - 読み間違えたら、**その文の最初から読み直して**、そのまま続ける（読み直しの前の失敗は、ツールが「どの文にも対応しない区間」として手本から外します。ただし途切れ方によっては取り違えるので、失敗が多いときは録り直すか、`--asr whisper` を使います）。
   - 漢字の読み方に迷う文は、右の「読み」のとおりに読む。
4. 外国語が話せる人は、続けて**任意の外国語**を読む（下の「5. 外国語」。日本語の朗読のあとに、英語→フランス語→中国語の順で）。
   - 読まない言語は飛ばしてよい。
5. 読み終わったら**2秒黙って**止め、WAV で保存する。

> **同意なしに他人の声を録音・登録しない。** 登録できるのは、本人が同意した声だけです。
> 録音ファイル（同意文入り）は、**同意の記録として、消さずに保管**してください。登録ツールは元の録音を複製しません。

---

## 3. 同意文（毎回、最初に読む。固定文）

下の【　】の所だけ、自分の情報に置き換えて読みます。それ以外の言葉は変えないでください。

| 【　】 | 入れる内容 | 例 |
|---|---|---|
| 【お名前】 | 自分のフルネーム | 山田 太郎 |
| 【組織名】 | 声の合成を管理・利用する組織名 | 株式会社○○ |
| 【保存期間】 | 声のデータを保存する期限 | 2027年3月末 |

> 私は【お名前】です。
> 【組織名】が、会議の翻訳と音声の読み上げのために、私の声から合成音声を作成し、利用することに同意します。
> 保存期間は【保存期間】までで、同意はいつでも撤回できます。

（画面で埋めた状態を見るには：`uv run voiceprofile script --speaker 山田太郎 --org 株式会社○○ --retention 2027年3月末`）

## 4. 日本語の朗読文（18文・約90秒）

会議で説明するときの自然な調子で、1文ずつ読みます。数字・日付・時刻は、**漢数字で書いてある**とおりに読みます。
右の「読み」は読み方の確認用です（これを見て読む必要はありません）。

どの文も、ふだんの会議で出てくる言い方にしてあります。日本語のすべての音（清音・濁音・半濁音・拗音〈きゃ・しゅ・ちょ など〉・促音〈っ〉・長音〈ー〉・撥音〈ん〉）と、
外来語で使う音（ファ・フィ・ティ・ウィ・ジェ・シェ・チェ など）が、一通り入るように作ってあります。

| 番号 | 文 | 読み |
|---|---|---|
| ja01 | それでは、定例の設計レビューを始めます。 | それでは、ていれいのせっけいレビューをはじめます。 |
| ja02 | まず、資料の三ページ、三月十二日の衝突試験の結果から確認します。 | まず、しりょうのさんページ、さんがつじゅうににちのしょうとつしけんのけっかからかくにんします。 |
| ja03 | 車両の衝突から三百ミリ秒後に、逆方向の加速度が出ています。 | しゃりょうのしょうとつからさんびゃくミリびょうごに、ぎゃくほうこうのかそくどがでています。 |
| ja04 | 取り付け部品の剛性不足の影響が、如実に表れました。 | とりつけぶひんのごうせいぶそくのえいきょうが、にょじつにあらわれました。 |
| ja05 | 二千ニュートンの荷重で、六百ヘルツ付近に妙なピークが出ました。 | にせんニュートンのかじゅうで、ろっぴゃくヘルツふきんにみょうなピークがでました。 |
| ja06 | グラフの波形がぴょんと跳ねる以外は、シミュレーションとほぼ一致しています。 | グラフのはけいがぴょんとはねるいがいは、シミュレーションとほぼいっちしています。 |
| ja07 | ただ、セーフティに関わる項目は、客観的な評価が不十分です。 | ただ、セーフティにかかわるこうもくは、きゃっかんてきなひょうかがふじゅうぶんです。 |
| ja08 | ガスの流量を、コンピュータ上で百パーセント再現するのは、ちょっと難しいです。 | ガスのりゅうりょうを、コンピュータじょうでひゃくパーセントさいげんするのは、ちょっとむずかしいです。 |
| ja09 | 測定チャンネルの増加に合わせて、ファイルのフォーマットとフィードバックを統一します。 | そくていチャンネルのぞうかにあわせて、ファイルのフォーマットとフィードバックをとういつします。 |
| ja10 | じゃあ、細かい点は略して、緊急のポイントだけ別途お願いします。 | じゃあ、こまかいてんはりゃくして、きんきゅうのポイントだけべっとおねがいします。 |
| ja11 | 発表は来週の金曜日、午後三時四十五分からです。 | はっぴょうはらいしゅうのきんようび、ごごさんじよんじゅうごふんからです。 |
| ja12 | 予算は、約八百五十万円を見込んでいます。 | よさんは、やくはっぴゃくごじゅうまんえんをみこんでいます。 |
| ja13 | ウェブ会議の方は、ウィンドウを共有して、ディスカッションに参加してください。 | ウェブかいぎのかたは、ウィンドウをきょうゆうして、ディスカッションにさんかしてください。 |
| ja14 | ボルトが抜けないように、ぎゅっと締めて、注意をお願いします。 | ボルトがぬけないように、ぎゅっとしめて、ちゅういをおねがいします。 |
| ja15 | ヒューマンエラーを減らすため、現場のインタビューも続けます。 | ヒューマンエラーをへらすため、げんばのインタビューもつづけます。 |
| ja16 | 次のフェーズは、プロジェクト全体でチェックして、結果をシェアしましょう。 | つぎのフェーズは、プロジェクトぜんたいでチェックして、けっかをシェアしましょう。 |
| ja17 | 脈絡がなくて恐縮ですが、業務の整理を先に進めます。 | みゃくらくがなくてきょうしゅくですが、ぎょうむのせいりをさきにすすめます。 |
| ja18 | 雑談ですが、昨日の昼食は、こんにゃくと大根の煮物でした。 | ざつだんですが、きのうのちゅうしょくは、こんにゃくとだいこんのにものでした。 |

読む速さの目安：1秒に7〜8モーラ（ふつうの会議で説明する速さ）。18文で、文のあいだの間（約1秒）を入れて **約90〜95秒**です。
読みにくい所は少しゆっくりでも構いません（その分、録音が長くなるだけです）。

## 5. 外国語（任意・各約15秒）

その言語を**ふだん使える人だけ**読みます（発音に自信がないものは飛ばしてください）。日本語の朗読のあとに、続けて読んでも、別の録音にしても構いません。
読みかたは日本語のときと同じです（自然な調子、文のあいだは1秒ほどあける）。数字や時刻は、書いてあるとおりの言葉で読みます。

### English（英語）
| 番号 | 文 |
|---|---|
| en01 | Good morning, everyone. Let's start with the crash test results from March twelfth. |
| en02 | The passenger side acceleration was slightly above the target, so we changed the thickness of the bracket. |
| en03 | I will share the new data by three forty-five on Friday afternoon. |

### Français（フランス語）
| 番号 | 文 |
|---|---|
| fr01 | Bonjour à tous. Commençons par les résultats de l'essai de choc du douze mars. |
| fr02 | L'accélération du côté passager dépasse légèrement la valeur cible, donc nous avons modifié l'épaisseur du support. |
| fr03 | Je partagerai les nouvelles données vendredi, à quinze heures quarante-cinq. |

### 中文（普通话・簡体字）
| 番号 | 文 |
|---|---|
| zh01 | 大家早上好。我们先来看三月十二日碰撞试验的结果。 |
| zh02 | 副驾驶一侧的加速度略微超过了目标值，所以我们修改了支架的厚度。 |
| zh03 | 新的数据我会在星期五下午三点四十五分之前分享给大家。 |

## 6. 録音のあと

- ファイル名は何でも構いません（例：`rec_yamada.wav`）。
- **元の録音は消さずに保管**（同意の記録です）。
- 次は `src/voiceprofile/README.md` の手順で `voiceprofile build` を実行します。台本は `enroll/script_ja.json` を指定すると、手本に書き起こし（読んだ文）が自動で付きます。
  日本語のあとに英語・フランス語・中国語を続けて録音した場合は、`--lang ja,en,fr,zh` のように読んだ順に指定します。

## 7. よくある失敗

| 症状 | 原因と対策 |
|---|---|
| 手本が3本取れない・短い | 録音が短い、または文のあいだの間（無音）が足りない。文のあいだを1秒ほどあけて録り直す |
| 報告書の「SNR」が低い（20 dB 未満） | 部屋の雑音が大きい。ファン・エアコンを止める、マイクを口に近づける（10 cm）、静かな時間帯に録る |
| 「割れ率」が 0 でない | 音が大きすぎる。マイクの音量を下げて録り直す |
| 「無音部分が完全に無音」の警告 | 録音ソフトにノイズゲート/ノイズ除去がかかっている。切って録り直す |
| 書き起こしの状態が「要確認」 | 読み飛ばし・言い直しで、録音の区間と台本の文の対応がずれた。録り直すか `--asr whisper` を付ける |
